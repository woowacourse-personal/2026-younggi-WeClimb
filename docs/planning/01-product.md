# We-Climb — 프로덕트 정의

> 이 문서는 UI 디자인의 입력이다. 이 문서만 보고 와이어프레임을 그릴 수
> 있어야 한다.

## 핵심 사용자 여정

```
[여정 1 — 세션 한 판]
홈 → 암장 선택(최근 암장 원탭) → 세션 보드
  ├─ 촬영: 색깔 선택 → 녹화 → 성공/실패 원탭 → 트리밍(또는 "나중에") → 보드 복귀
  └─ 칩 카운트: 색깔 탭 = +1
→ 세션 종료 → 한 컷 사진(스킵 가능) → 미룬 트리밍 일괄 + 실패 일괄 삭제
→ 리포트 완성 → 인스타 공유

[여정 2 — 재방문] 홈에서 잔디·최근 리포트가 먼저 보임 → 세션 시작
[여정 3 — 유입] 인스타에서 리포트 카드 → 카드의 브랜드 마크 → 설치
```

트리밍은 운동 중이 기본, 미루면 종료 플로우에 자동 큐잉. 인스타 업로드는
세션 직후 한 번에. 영상이 하나도 없어도 여정 1이 성립한다
(카운트 → 사진+리포트 → 공유).

## 화면 목록

### 1. 온보딩 (최초 1회)

- **목적**: 30초 안에 첫 세션 시작 가능하게
- **핵심 요소**: 간편 로그인(프로바이더 1개), 닉네임, 카메라/갤러리 권한
- **주요 상태**: 권한 거부 시 안내
- **이동**: → 홈

### 2. 홈

- **목적**: 세션 시작 발사대 + 리텐션 훅
- **핵심 요소**: [세션 시작] 대형 버튼, 최근 암장 원탭, 잔디(주간 활동),
  최근 세션 리포트 썸네일
- **주요 상태**: 첫 실행(빈 상태 — "첫 세션을 시작해보세요") / 기록 있음
- **이동**: → 암장 선택 → 세션 보드, 하단 탭 ↔ 기록

### 3. 암장 선택

- **목적**: 기록의 기준점(지점) 확정
- **핵심 요소**: 검색(지도 데이터), 최근 목록, 직접 추가(lazy creation)
- **주요 상태**: 검색 결과 없음 → 직접 추가 유도
- **이동**: 홈 → 여기 → 세션 보드

### 4. 세션 보드

- **목적**: 운동 중 유일하게 보는 화면 — 최소 UI
- **핵심 요소**: 타이머, 색깔 칩 그리드(탭=+1), [촬영] 대형 버튼,
  오늘 요약 한 줄, [세션 종료]
- **주요 상태**: 미룬 트리밍 뱃지
- **이동**: ↔ 촬영, → 세션 종료 플로우

### 5. 촬영 (인앱 카메라)

- **목적**: 찍는 행위가 곧 분류
- **핵심 요소**: 현재 색깔 표시(변경 가능), 녹화 시작/정지, 정지 직후
  [성공/실패] 오버레이, 같은 문제 재시도는 같은 인덱스로 묶음
- **주요 상태**: 실패 → 삭제 대기함 / 성공 → 트리밍
- **이동**: 세션 보드 ↔ 여기 → 트리밍

### 6. 트리밍

- **목적**: 앞뒤 죽은 시간 제거
- **핵심 요소**: 타임라인 + 시작/끝 핸들, 미리보기, [저장] / [나중에 할래요]
- **이동**: 촬영 → 여기 → 세션 보드

### 7. 세션 종료 플로우

- **목적**: 리포트 재료 완성
- **핵심 요소**: 7a 한 컷 사진 촬영(스킵 시 기본 카드) → 7b 미룬 트리밍 큐
  일괄 처리("원본 그대로" 선택지 포함) + 실패 영상 일괄 삭제 확인 → 7c 리포트로
- **주요 상태**: 미룬 트리밍 없으면 7b 스킵
- **이동**: 세션 보드 → 여기 → 리포트

### 8. 리포트 (이 앱의 얼굴)

- **목적**: 세션을 자랑 가능한 형태로 완성 + 유입 장치
- **핵심 요소**: 한 컷 사진 배경 + 오버레이(암장명·날짜·운동 시간·총 완등·
  색깔별 분포·최고 난이도), 성공 영상 썸네일 스트립, [인스타 공유](스토리
  규격), [갤러리 저장], 브랜드 마크
- **주요 상태**: 영상 있음/없음 레이아웃 분기
- **이동**: 종료 플로우 → 여기 → 공유 → 홈

### 9. 기록 탭 (아카이브 + 통계)

- **목적**: 쌓일수록 예뻐지는 화면 — 리텐션 훅
- **핵심 요소**: 상단 통계(잔디·색깔별 분포·누적), 세션 리스트(리포트 카드)
  → 세션 상세(리포트 + 영상들)
- **주요 상태**: **영상이 기기에서 삭제됨** → "영상은 삭제됐지만 기록은
  남아있어요" 플레이스홀더
- **이동**: 하단 탭 ↔ 홈

## 이후 단계 화면 (MVP 제외)

- 루트별 영상 모아보기·베타 요청·댓글 — 3단(암장 밀도 후)
- 체감 난이도 투표(옵셔널)·집계 — 3단
- 월간 리캡, V등급 추정 — 데이터 쌓인 뒤
- 들찍 모드(자동 팔로우 프레이밍) — 기술 검증 후
- 랜딩 페이지 — 리포트 카드가 당분간 랜딩 역할
