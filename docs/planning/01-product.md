# We-Climb — 프로덕트 정의

> 이 문서는 UI 디자인의 입력이다. 이 문서만 보고 와이어프레임을 그릴 수
> 있어야 한다. (2026-07-15 아이데이션 결정 반영본)

## 색·등급 시스템 (핵심 데이터 모델)

색은 **물리적 입력**, 난이도는 **계산 단위**로 분리한다.

- **앱 표준 등급 = Lv.1~9, 색이 곧 레벨**: 빨(1,쉬움)·주(2)·노(3)·초(4)·
  파(5)·남(6)·보(7)·갈(8)·검(9,어려움). 온보딩·홈·기록 통계가 이 9색을 씀.
- **입력 = 암장의 실제 테이프 색**: 유저는 벽에서 본 색 그대로 탭/촬영.
- **암장별 색→앱레벨 매핑**: 프랜차이즈 프리셋 + 직접. "파랑@닻 = Lv.5"처럼
  암장마다 다름. 표기는 "Lv.5 파랑"(숫자+색).
- **표시 규칙**: **세션 보드·세션 상세는 암장 실제 색**(벽과 매칭, 알아보기
  쉽게), **홈·기록 통계는 앱 9색**. 둘의 차이는 암장 선택 화면의 색 비교로
  바로 보여줌.
- **집계는 앱 레벨 기준** → 암장 가로질러 비교 가능.

## 실력 가늠자 (리텐션/성장의 축)

경험치·XP 그라인드는 쓰지 않는다(앱 성격과 불일치, 조작 취약). 대신 내 완등
이력을 등급으로 환산한 **실력 평가**를 쓴다 — 합산이 아니라 **최댓값 기반**이라
칩 연타로 부풀릴 수 없다.

- **홈 히어로 = 내 현재 실력 등급(Lv) + 등급별 색으로 쌓이는 누적 성장 곡선.**
  맥락(클라이밍 하러 켰는지)과 무관하게 항상 의미 있음.
- **암장별 안내는 "세션 시작(암장 선택)" 순간에만** 노출: "닻에서 넌 파랑까지
  완등 · 빨강 도전" (컴포트 + 스트레치, 그 암장 색으로). 실제로 뭘 붙을지
  정하는 순간이라 정보가 환영받는다.
- **콜드스타트**: 기록 0인 신규 유저는 온보딩에서 자기평가 1회로 시작점을
  잡고, 기록이 쌓이면 자동 보정.

## 핵심 사용자 여정

```
[여정 1 — 클라이밍 한 판]
홈 → 클라이밍 시작 → 암장 선택(+ "여기선 파랑까지·빨강 도전" 안내) → 세션 보드
  ├─ 촬영: 색깔 선택 → 녹화 → 성공/실패 원탭 → 트리밍(또는 "나중에") → 보드 복귀
  └─ 칩 카운트: 색깔 탭 = +1 (등급으로 환산 기록)
→ 세션 종료 → 한 컷 사진(필수) → 미룬 트리밍 일괄(자르기/안 하면 원본)
  + 실패 영상 정리(기본 전체 삭제, 남길 것만 제외) → 리포트 → 인스타 공유

[여정 2 — 재방문] 홈에서 내 실력 등급·성장 곡선·최근 리포트가 먼저 보임
[여정 3 — 유입] 인스타의 리포트 카드 → 카드의 브랜드 마크 → 설치
```

트리밍은 운동 중이 기본, 미루면 종료 플로우 큐로. 인스타 업로드는 세션 직후
한 번에. 영상이 하나도 없어도 여정 1이 성립한다(카운트 → 사진+리포트 → 공유).

## 화면 목록

### 1. 온보딩 (최초 1회)

- **목적**: 첫 클라이밍 시작 + 실력 가늠자 시작점 확보
- **핵심 요소**: 간편 로그인(프로바이더 1개), 닉네임, **실력 자기평가 1스텝**
  (9색 스케일 세로 배치, 검정 위→빨강 아래, 평균 완등 난이도 하나 선택),
  카메라/갤러리 권한
- **주요 상태**: 자기평가 스킵 시 "기록 쌓이면 잡아드려요"
- **이동**: → 홈

### 2. 홈

- **목적**: 클라이밍 시작 발사대 + 리텐션 훅(내 실력·성장이 먼저 보임)
- **핵심 요소**: **실력 스냅샷(현재 Lv + 등급별 색 누적 성장 곡선)**,
  [클라이밍 시작] 대형 버튼, 최근 리포트 카드. ※ "바로 시작(최근 암장 원탭)"
  제거, "세션"→"클라이밍" 용어
- **주요 상태**: 첫 실행(빈 상태 — "첫 클라이밍을 기록해보세요") / 기록 있음
- **이동**: → 암장 선택, 하단 탭 ↔ 기록

### 3. 암장 선택 (+ 실력 안내 + 색 비교)

- **목적**: 기록 기준점(지점) 확정 + **이 암장에서 뭘 붙을지 안내**
- **핵심 요소**: 검색(지도 데이터), 최근 목록, 직접 추가(lazy creation).
  암장 선택 시 **"여기선 컴포트=○색까지 · 스트레치=○색 도전"** 안내 +
  **암장 색 ↔ 앱 레벨색 비교표**(이 암장 파랑 = 앱 Lv.5 등 오프셋 확인) +
  **[이 암장에서 시작] 진행 버튼**. ※ "너" 지칭 안 씀
- **주요 상태**: 매핑 없는 암장 → 프리셋/직접 매핑 유도 · 이력 부족 → "기록 쌓는 중"
- **이동**: 홈 → 여기 → 세션 보드

### 4. 세션 보드

- **목적**: 운동 중 유일하게 보는 화면 — 최소 UI
- **핵심 요소**: 타이머, **레벨별 늘어나는 바**(그 암장 색만, 낮은 등급→높은
  등급 순). 탭=+1로 바가 차고 **5개마다 꽉 참 → 다음 5개는 더 진한 색으로
  다시 채워짐**(반복, ×N 뱃지). [촬영] 버튼, 오늘 요약, [클라이밍 종료]
- **주요 상태**: 미룬 트리밍 뱃지
- **이동**: ↔ 촬영, → 세션 종료 플로우

### 5. 촬영 (인앱 카메라)

- **목적**: 찍는 행위가 곧 분류
- **핵심 요소**: 현재 색깔 표시(변경 가능), 녹화 시작/정지, 정지 직후
  [성공/실패] 오버레이, 같은 문제 재시도는 같은 인덱스로 묶음
- **주요 상태**: 실패 → 삭제 대기함 / 성공 → 트리밍
- **이동**: 세션 보드 ↔ 여기 → 트리밍

### 6. 트리밍

- **목적**: 앞뒤 죽은 시간 제거
- **핵심 요소**: 타임라인 + 시작/끝 핸들, 미리보기(재생), [자르기]. **안 하면
  원본 그대로 저장**("나중에 할래요"는 종료 플로우 큐로)
- **이동**: 촬영 → 여기 → 세션 보드

### 7. 세션 종료 플로우

- **목적**: 리포트 재료 완성
- **핵심 요소**: 7a **한 컷 사진 촬영(필수)** → 7b 미룬 트리밍 큐(항목별
  [자르기], 안 누르면 원본 업로드) + **실패 영상 정리(기본 전체 삭제 예정,
  남길 것만 탭해서 제외)**. **각 영상은 탭해서 재생/확인 가능** → 7c 리포트로
- **주요 상태**: 미룬 트리밍 없으면 7b의 트리밍 파트 스킵
- **이동**: 세션 보드 → 여기 → 리포트

### 8. 리포트 (이 앱의 얼굴)

- **목적**: 세션을 자랑 가능한 형태로 완성 + 유입 장치
- **핵심 요소**: 한 컷 사진 배경 + 오버레이(암장명·날짜·**운동 시간·총 완등·
  최고 난이도(색 이름)** + **레벨별 완등 개수 가로 바 그래프**), [인스타 공유]
  (스토리 규격), [갤러리 저장], 브랜드 마크. ※ 영상 스트립 제거, "지난 주
  대비"·"색깔 수" 제거, **리포트에는 Lv 숫자 안 씀(색 이름만)**
- **주요 상태**: 영상 있음/없음 무관 동일 레이아웃(사진+수치 중심)
- **이동**: 종료 플로우 → 여기 → 공유 → 홈

### 9. 기록 탭 (아카이브 + 통계)

- **목적**: 쌓일수록 예뻐지는 화면 — 리텐션 훅
- **핵심 요소**: **등급별 색 누적 성장 곡선 + 볼륨 숫자(총 완등·세션·이번 달
  N회)**, **등급별 완등 분포**, 세션 리스트(리포트 카드) → 세션 상세(리포트 +
  영상들, 원본 색 표시). ※ 이번 달 잔디 제거
- **주요 상태**: **영상이 기기에서 삭제됨** → "영상은 삭제됐지만 기록은
  남아있어요" 플레이스홀더
- **이동**: 하단 탭 ↔ 홈

## 이후 단계 화면 (MVP 제외)

- 루트별 영상 모아보기·베타 요청·댓글 — 3단(암장 밀도 후)
- 체감 난이도 투표(옵셔널)·집계 — 3단
- 월간 리캡 — 데이터 쌓인 뒤
- 경험치/랭킹 — 소셜(4단)에서 영상 검증 전제로만 재고
- 들찍 모드(자동 팔로우 프레이밍) — 기술 검증 후
- 랜딩 페이지 — 리포트 카드가 당분간 랜딩 역할
