# We-Climb - 브리프

> 완등 영상을 남기고 싶은 클라이머가, 등반 중 이 앱으로 촬영만 하면,
> 성공 컷 선별, 트리밍, 기록, 인스타 공유까지 한 플로우로 끝나게 해주는
> 클라이밍 전용 카메라 앱

## 문제와 타겟

- **타겟**: 주 1회 이상 정기 방문하는 성취 지향 클라이머. 영상을 찍는
  유저(한계 도전, 까리한 무브에서 촬영)와 안 찍는 유저(카운트만 기록) 모두.
  라이트/이탈 유저는 타겟 밖
- **문제**: 한 세션에 50~100개씩 쌓이는 시도 영상에서 성공 컷을 골라내고,
  앞뒤를 잘라내고, 라벨을 붙이는 정리 노동이 등반 시간보다 길다 - 성취의
  영상이 앨범에서 죽는다 (유저 인터뷰 6건으로 검증)
- **현재의 대안**: 기본 카메라로 찍고 수동 정리 후 인스타 부계에 아카이빙.
  "편집에 한두 시간" - 시간을 쓰는 수준의 고통

## 핵심 가치

- **한 문장 가치 제안**: "이걸로 찍으면 세션 끝나는 순간 자랑할 리포트가
  완성돼 있어" - 클라이밍의 Nike Run Club
- **결정적 차별점**: 클라이밍 특화 촬영→분류→트리밍 파이프라인(기존 클라이밍
  앱에 없음) + NRC식 세션 리포트. 영상은 로컬+인스타에, 서버엔 메타데이터만
  (비용 구조상 지속 가능)

## 도메인 역학

- **콜드스타트**: 없음(N=1 도구). 암장 지점 데이터만 출처, 재사용 조건을
  검증한 수동 시드 또는 승인된 장소 API로 준비, 벽/색깔은 첫 기록자가 생성
- **획득 경로**: ① 크루 직접 배포 - 크루 문화 특성상 1명이 쓰면 크루 단위
  확산, ② 인스타에 공유된 리포트 카드 유입. **리포트 카드가 곧 마케팅 채널**
- **리텐션 훅**: 실력 가늠자(내 현재 등급 + 등급별 색 누적 성장 곡선) +
  세션 시작 시 암장별 "뭘 붙을지" 안내. 기록이 쌓일수록 예뻐지고 조언이
  정확해지는 화면. (경험치, 잔디는 앱 성격/조작 문제로 배제 - 앱 표준 등급
  Lv.1~9(빨=쉬움~검=어려움, 색이 곧 레벨)로 암장 색을 환산해 가로질러 비교)
- **수익**: 미룸 (B2B 세터 대시보드는 후일 가능성으로만)

## 범위와 성공 기준

- **플랫폼**: 모바일 앱 - Kotlin + KMP 뼈대(Android 먼저, iOS는 구조만 준비),
  백엔드 **Supabase(MVP) → Spring Boot 이관 확정**, **개인, 풀타임, MVP 2주**
  (상세: [03-tech-decisions.md](03-tech-decisions.md))
- **절대 안 빼는 것**: 촬영→리포트→인스타 원플로우 + 아카이빙, 통계 /
  **이번에 안 하는 것**: 앱에서 남의 콘텐츠 보기
- **성공 기준**: 크루 5명이 2회 이상 이 앱으로만 찍고 리포트를 올림
