# Gemini Canvas 프롬프트 — MVP 전체 화면 구성 (01-product.md 기반)

> 목적: 확정된 9개 화면의 구성·플로우를 눈으로 확인하는 인터랙티브 목업.
> 아래를 Gemini Canvas에 그대로 붙여넣기.

---

```
볼더링 기록 앱 "We-Climb"의 인터랙티브 프로토타입을 단일 HTML 모바일
웹앱으로 만들어줘. 폭 390px 중앙 정렬, 한국어 UI, 다크 테마(배경 #111),
클라이밍 홀드 색깔(하양·노랑·초록·파랑·빨강·보라)을 포인트로.
모든 버튼과 화면 전환이 실제로 동작해야 하고, 더미 데이터는 진짜같은
한국 암장명(닻 클라이밍, 더클라임 양재 등)을 쓸 것.

컨셉 한 줄: "클라이밍의 Nike Run Club" — 촬영부터 세션 리포트,
인스타 공유까지 한 플로우.

━━━ 화면 1: 온보딩 (첫 진입) ━━━
로고 "✦ We-Climb" + 한 줄 소개 → [Google로 계속하기] 버튼 →
닉네임 입력 → 카메라/갤러리 권한 안내 카드 → 홈으로.

━━━ 화면 2: 홈 (하단 탭: 홈 | 기록) ━━━
- 상단: 인사말 + 이번 주 잔디(7칸, 운동한 날 채움)
- 중앙: [세션 시작] 대형 버튼
- 그 아래: 최근 암장 원탭 칩 ("닻 클라이밍에서 바로 시작")
- 하단: 최근 세션 리포트 썸네일 카드 1장
- 첫 실행 상태도 토글로 볼 수 있게: "첫 세션을 시작해보세요" 빈 상태

━━━ 화면 3: 암장 선택 ━━━
검색창 + 최근 목록(닻 클라이밍, 더클라임 양재) + 검색 결과 없을 때
"직접 추가하기" 버튼. 선택하면 세션 보드로.

━━━ 화면 4: 세션 보드 (운동 중 메인) ━━━
- 상단: 암장명 + 큰 타이머(자동 증가)
- 중앙: 색깔 칩 6개 그리드 — 탭하면 완등 카운트 +1 (애니메이션)
- [📹 촬영] 대형 버튼 (화면의 주인공)
- 하단: 오늘 요약 한 줄 ("12문제 · 최고 파랑") + [세션 종료]
- 미룬 트리밍이 있으면 종료 버튼 옆 뱃지 "트리밍 2개 대기"

━━━ 화면 5: 촬영 (인앱 카메라) ━━━
- 카메라 프리뷰(어두운 그라데이션 더미 + 클라이밍 벽 느낌)
- 상단: 현재 문제 색깔 칩 (탭하면 변경)
- 중앙 하단: 녹화 버튼 (누르면 REC 표시 + 타이머)
- 정지하면 즉시 오버레이: [✅ 성공] [❌ 실패] 대형 버튼 2개
  - 실패 → "삭제 대기함에 담김" 토스트 → 카메라로 복귀
  - 성공 → 트리밍 화면으로

━━━ 화면 6: 트리밍 ━━━
- 영상 미리보기 영역(더미) + 타임라인 바 + 좌우 핸들(드래그 가능한 느낌)
- 버튼 2개: [저장] / [나중에 할래요]
- 저장하면 "저장됨 + 파랑 1 완등 기록" 토스트 → 세션 보드 복귀

━━━ 화면 7: 세션 종료 플로우 (3단계 스텝 인디케이터) ━━━
7a. "오늘의 한 컷을 남겨요" — 사진 촬영 버튼 + [건너뛰기]
7b. "미뤄둔 트리밍 2개" — 큐 목록, 각 항목에 [자르기] [원본 그대로],
    아래에 "실패 영상 5개 모두 삭제할까요?" [삭제] [보관]
7c. 완료 → 리포트로

━━━ 화면 8: 리포트 (이 앱의 얼굴 — 제일 공들일 것) ━━━
Nike Run Club 러닝 리포트 감성. 9:16 카드:
- 배경: 한 컷 사진(어두운 클라이밍장 느낌 더미) + 그라데이션
- 오버레이: "닻 클라이밍 · 7월 15일 · 1시간 24분",
  큰 숫자 "14 완등", 색깔별 분포 미니 바 차트, "최고 난이도 파랑",
  하단에 성공 영상 썸네일 스트립(가로 스크롤 4개)
- 우하단 브랜드 마크 "✦ We-Climb"
- 카드 아래 버튼: [인스타 스토리로 공유] [갤러리 저장]
- 영상 없는 세션 상태도 토글: 사진+수치만으로 구성된 버전

━━━ 화면 9: 기록 탭 ━━━
- 상단 통계: 월간 잔디, 색깔별 완등 분포 가로 막대, 누적 수치
  ("총 87문제 · 12세션")
- 아래: 날짜별 세션 리포트 카드 리스트 → 탭하면 세션 상세
  (리포트 + 영상 썸네일들)
- 영상이 기기에서 삭제된 항목: 썸네일 자리에 회색 플레이스홀더
  "영상은 삭제됐지만 기록은 남아있어요"

첫 로드는 화면 2(홈)에서 시작하고, 우상단에 개발용 화면 점프 메뉴
(1~9 바로가기)를 작게 넣어줘.
```
