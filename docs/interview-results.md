# 인터뷰 결과

## #1 — 2026.07.13 (16분)

### 프로필

| 항목 | 내용 |
|---|---|
| 구력/빈도 | 2년 / 주 1회 |
| 주 암장 | 없음 — 크루가 그때그때 정함. 선호 브랜드는 있음 (정적인 스타일 선호) |
| 유형 | 라이트~미드 유저, 크루 중심 |

### 가설 판정

| 가설 | 판정 | 근거 |
|---|---|---|
| 1 남긴다 | △ | "예전에는 많이 했고 지금은 개수만, 머리로." 포기 이유 = 귀찮아서. 더클라임 앱 기록 기능 존재하나 평판 나쁨 |
| 2 자랑한다 | ✅ | 부계정 운영(엄마아빠 DM 때문), 올리는 이유 "그냥 자랑용" |
| 3 동기 | ✅ | 실력 척도 없음. 유일한 객관 척도 = 암장 페스티벌 랭킹(200명 중 150등, 정확히 기억) |
| 4 베타 | △ | 인스타에서 암장 태그로 "찾으려면 찾을 수 있다, 근데 귀찮다" — 마찰 확인, 절박함 약함 |
| 5 내보내기 | 데이터 없음 | 질문 누락 — 다음 인터뷰에서 필수 |

### 사실 교정 (중요)

- **세팅은 월 1회 일괄이 아니라 벽 단위 주간 순환.** "벽 4개면 주에 하나씩
  번갈아 바꾼다." → 루트 엔티티 = 지점 × 벽 × **세팅 회차** × 색깔.
  탈거 알림(⑪) 기회가 매주 발생하는 부수효과.

### 발견

1. **인스타에 세터 공식 정답지 문화 존재.** "세팅하면 세팅하신 분이 정답을
   올려요." → 3단 오픈 시 세터 정답 영상 링크만 붙여도 루트 페이지가 첫날부터
   유용 (콘텐츠 콜드스타트 해결). 세터는 알려져 있고 성향이 암장 성격을 결정
   → 팔로우 가치 있는 엔티티.
2. **색깔 내 체감 난이도 니즈 (유일하게 본인이 먼저 꺼낸 기능).** "보라에
   가까운 핑크, 빨강에 가까운 핑크. 세터는 핑크로 냈는데 빨강 수준인 것 같은."
   → 체감 난이도 투표 = V등급 추정(②)의 원료. MVP 편입 후보.
3. **문제 유형 태그 + 성향.** "밸런스/다이나믹/스테밍 문제… 나는 정적인 것만
   많이 풀고, 안 맞는 암장은 덜 간다." → 무브 태그·약점 분석 니즈 실증,
   성향 기반 암장 추천으로 확장 가능.
4. **선택적 기록.** "쉬운 건 찍어도 의미 없다. 재밌던 것, 잘 안 됐던 것만."
   → 기록 UX는 2단: 개수는 색깔 카운트로 초경량, 의미 있는 문제만 영상+태깅.
5. **세션 종료 UX 힌트.** "집에 갈 때 한 바퀴 쭉 돌면서 '이거 이거 했다'" —
   이 회상 행동을 세션 종료 화면으로 옮기면 됨.
6. 티어/랭킹 지지: "성취 위주 운동이라 정량 판단이 가능해서 있으면 있을수록
   좋다" (단, 아이디어 설명 후 발언이라 오염 가능성 감안).
7. 경쟁: 더클라임 앱(기록 기능 있음, 평 나쁨) — 왜 안 쓰는지 다음에 확인.

### 경고 신호

- "제일 아쉬운 것" 질문에 답 못 함("그러게요") → 불편이 잠재적(latent).
  만들면 좋아하지만 스스로 찾아오진 않는 제품일 위험 — 성장 채널(내보내기)
  중요성 상승.

### 다음 인터뷰(2·3번) 보완

1. 가설 5 질문 필수: "올리기 전에 편집 했어요? 뭐가 귀찮았어요?"
2. "제일 아쉬운 것" 리프레이징: "친구가 클라이밍 시작하면 '이건 불편할
   거야'라고 말해줄 게 있어요?"
3. 추가 확인: 세터 정답지 보는 빈도 / 더클라임 앱 기록 왜 안 쓰는지 /
   체감 난이도 니즈가 재현되는지
4. 대상: 주 2회 이상 헤비 유저로 스펙트럼 채우기

## #2 — 2026.07.13 (8분)

### 프로필

| 항목 | 내용 |
|---|---|
| 구력/빈도 | 2년 / 과거 월 1~2회 → 현재 사실상 이탈 (마지막 방문 2달 전) |
| 주 암장 | 없음 (과거 수원에 선호 암장, 멀어서 안 감) |
| 유형 | **라이트/이탈 유저 — 타겟 밖** |

### 가설 판정

| 가설 | 판정 | 근거 |
|---|---|---|
| 1 남긴다 | ❌ | 영상·기록 전혀 안 함. "그때 재밌어서 한" — 기록 욕구 자체가 없음 |
| 2 자랑한다 | ❌ | "사진 찍어서 인스타 이런 거 많이 하잖아요, 근데 저는 그렇게까지는" |
| 3 동기 | △ | 척도는 역시 모호("중간에서 중상"). 성장 감각은 질적(기술·근육 사용 변화)으로만 — 정량 니즈 약함 |
| 4 베타 | ✅ | 실제 행동 확인: 스스로 분석 → 안 되면 "인스타에 보통 해답이 나오더라" → 따라해서 되면 풀이 문제, 안 되면 신체 문제로 진단. **인스타 정답지 문화 2번째 재확인** |
| 5 내보내기 | 해당 없음 | 애초에 안 올리는 사람 |

### 발견

1. **타겟 경계선 확정.** 기록·자랑·성장 니즈는 "주기적으로 가는 성취 지향
   유저"에게만 있다. 라이트/이탈 유저는 재미의 원천이 "문제 풀이 + 같이 간
   사람들"이라 기록할 이유가 없음. → MVP 페르소나 = 주 1회 이상 정기 방문 +
   성취 지향. 라이트 유저는 4단(피드)의 시청자로만 상정.
2. **핸드폰 용량이 기록의 실제 장벽.** "영상 다 찍으면 용량이… 저장·관리하는
   것보다 이득이 (있나)" → "용량 걱정 없는 완등 영상 보관"이 셀링 포인트가
   될 수 있음 (서버 비용과 트레이드오프 — 트리밍(⑮)이 비용 방어).
3. 베타 참고 행동이 비기록 유저에게도 있음 — 루트 페이지(④)의 잠재 소비자는
   타겟보다 넓다.
4. 본인 예측: "클린이(뉴비)나 고수들이 많이 쓸 것" — 성장 요소는 몰입 유저용
   이라는 인식.
5. 뉴비 온보딩 문화: 첫 완등 기억 = 고인물이 도와준 것. 커뮤니티 따뜻함이
   진입 경험의 핵심.
6. 경쟁 정보(인터뷰어 발언): 기존 클라이밍 커뮤니티 앱이 약 3달 전(2026년
   4월경) 서비스 종료 — 이름 확인 필요.

### 인터뷰 품질 메모

- "클라이밍은 자랑 절반, 성취 절반이라고들 하는데" — 유도성 발언 있었음.
  다음 인터뷰에서는 프레임 없이 열린 질문 유지할 것.

## #3 — 2026.07.13 (15분)

### 프로필

| 항목 | 내용 |
|---|---|
| 구력/빈도 | 1년 2개월 / **과거 주 3회** → 현재 월 1~2회 (부트캠프로 급감, 지난주도 방문) |
| 주 암장 | 있음 — 집 근처 "닻 클라이밍" (동네 암장, 한산해서 선호, 낯가림) |
| 유형 | (원래) 헤비 유저 + **동네 암장 세그먼트** |

### 가설 판정

| 가설 | 판정 | 근거 |
|---|---|---|
| 1 남긴다 | **✅ (최강 신호)** | "기록을 **어떻게 해야 될지 잘 모르겠어**. 1주마다 벽을 바꾸는데 '파트원에 초록색' 이렇게 기록할 수도 없고" — 안 하는 이유가 귀찮음이 아니라 **체계 부재**. 루트 엔티티가 정확히 이걸 해결 |
| 2 자랑한다 | ✅ | 다이노 완등 영상을 "뿌듯해서" 인스타에 올림, 반응(따봉)에 "매우 좋았다". 올리기 전 "흉측해 보여서 말까" 고민 |
| 3 동기 | ✅ | 실력 표현 "클린이, 매달려만 있는다" — 3명 연속 모호. **"더클 몇 단계가 어느 정도 수준인지 모른다, 동네 암장이라"** — 암장 간 비교 불가 문제 직접 증언. 성장 감각은 색깔 띠 + 풀업 개수(정량 지향 있음) |
| 4 베타 | △ | 눈팅은 함, 인스타는 "뜨면 보는 정도". 검색 안 함 — **"검색이 된다는 생각을 안 했다. 더클이면 되는데 동네니까"**. 대신 상주 고수에게 직접 질문(서로 이름 아는 사이) |
| 5 내보내기 | △ (힌트만) | "흉측해 보여서 올릴까 말까" = 영상 퀄리티 마찰의 간접 증거. 편집 질문은 또 누락 |

### 발견

1. **쐐기 가설의 가장 강한 지지.** "어떻게 기록해야 할지 모르겠다"는
   기록 욕구가 있는데 벽이 주마다 바뀌는 구조 때문에 기록 **체계**가 없다는
   증언 — 우리 루트 엔티티(지점×벽×세팅회차×색깔)가 문제를 정면 해결.
2. **동네 암장 세그먼트 발견.** 메인 브랜드(더클) 밖 동네 암장은: 인스타
   검색이 안 되고(콘텐츠 공백), 타 암장과 실력 비교 불가하고, 대신 오프라인
   커뮤니티가 강함(이름 알고 직접 물어봄). 루트 페이지·공통 척도의 가치가
   오히려 더 큰 롱테일 시장일 수 있음.
3. **영상 안 찍는 새 이유: 운동 흐름.** "30분 안 쉬고 빡빡 하고 나가는
   편이라 굳이" — 기록 UX는 세션 중 강제가 아니라 **세션 후 일괄**이 맞다는
   힌트 (#1의 "집 갈 때 한 바퀴 회상"과 일치).
4. 뿌듯한 완등만 찍음 — 선택적 기록 3명 중 2명 재현.
5. **유저 제안 기능 (아이디어 주차장 → 3~4단 후보)**:
   - 배틀/도전장: "나 풀었다, 너도 가능?" 친구에게 문제 도전 보내기
   - 코치 요청: 실패 영상 올리고 "코치 가능?" 요청
   - "그냥 공유가 아니라 **교류**할 수 있는 거" — 소셜 설계의 방향 힌트
6. 본인이 꼽은 유일한 불편 = **혼잡도** ("사람 없을 때 가고 싶다").
   아이디어 주차장행. 단, "아쉬운 것" 질문에 처음엔 "딱히" — 잠재 니즈
   패턴 3명 연속.
7. 라이프 이벤트(부트캠프)로 주3회→월1~2회 급감 — 리텐션의 외생 변수.

# 2차 인터뷰 (2026.07.14 — 데모 피드백 + 도메인 심층)

## #4 티뉴 (8분) — 헤비 촬영 유저

- **장벽②(정리 노동) 강력 실증**: "정리하는 게 진짜 귀찮거든. 한 번 갔다
  오면 영상 50~100개 쌓여. 멀리서 찍으니까 구분도 잘 안 가."
- **앱 내 촬영을 본인이 먼저 제안**: 앱↔카메라 왔다갔다가 더 불편 →
  색깔 누르면 카메라 → 완등/포기 버튼 → 카운트 자동.
- **문제 단위 인덱스 구조 제안**: 빨강 안에서도 문제별로 뎁스 하나 더
  (같은 문제의 시도 영상들이 묶이게). "카테고리가 잘 돼야 돼."
- 실패 영상 삭제는 강제 말고 유저 선택으로. "이거 빼고 다 지우기" 기능.
- 정리 시점: "집에 가는 길. 인스타에 올려야 되니까 한 번은 정리한다."
- 체감 난이도 5단계안: 아랫색인듯/쉬운 빨강/딱 빨강/어려운 빨강/윗색인듯.
- 성공 여부 자동 판정은 후순위, 유저 클릭이면 충분.
- 혼잡도 니즈 (또 등장, 누적 2회).

## #5 아티 (36분) — 라이트 촬영 유저, UX 비판

- **체감 투표 강제 노출 반감**: "설문까지 해버리는 느낌. '저희 어플
  어떠셨어요?' 물어보는 것 같다" → **원할 때만 노출(옵셔널)로 변경 확정.**
- **촬영 먼저, 태깅은 나중**: "눌러만 놓고 계속 하고 싶다. 찍을 때마다
  색깔 고르라는 게 불편" → 업로드/확정 시점에 색깔 선택 제안.
- **세그먼트 분화 발견**: "나는 몇 개 풀었는지 안 세. 그럴듯하게 올라간
  장면만 담고 싶다" — 카운터형(티온·티뉴) vs 하이라이트형(아티).
- 전체 공개 부담("얼굴 나오니까") → 크루/방 단위 공유 선호. 선택제면 OK.
- **로컬 저장의 함정**: "내 로컬에 저장될 거면 그냥 일반 카메라로 찍을 것
  같은데" — 앱 내 촬영+무언가 더 없으면 존재 이유가 없다는 경고.
- 서버 비용 감각: 30초 영상 ≈ 50MB, 인당 10개면 500MB — 서버 저장 비현실.
- **핵심 조언: 귀찮음을 분해하라** — ①개수 세기가 귀찮은가 ②앞뒤 자르기가
  귀찮은가 ③100개 중 성공작 추리기가 귀찮은가. 답에 따라 플로우가 달라진다.
- 사회적 증거: 클라이밍 커플이 끝나고 고깃집에서 둘 다 말없이 영상만 자르고
  있는 인스타툰이 밈화 — 편집 고통은 보편적.

## #6 티온 (28분) — 고수 헤비 유저

- **"편집을 대신해주면 쓴다"** — "편집하는 데 한두 시간 쓴 적 굉장히 많아.
  일반 사람들은 등반 시간보다 편집 시간이 길지 않을까."
- **편집 니즈 분해 (아티의 질문에 대한 답)**: ①앞뒤 자르기 ②실패 영상
  분류 ③하이라이트 뽑기 중 — **①+②만 해줘도 쓴다.** 하이라이트는 본인이
  고르면 됨 (③의 자동화는 어렵고 불필요).
- **이상적 플로우를 본인이 설계**: "앱에서 눌러 찍어 → 성공/실패 → 실패는
  바로 버려(어차피 안 봐) → 성공은 앞뒤 잘려서 바로 아카이빙 →
  **등반하는 내내 그 앱을 통해서만 찍는 거지.**" 색깔 자동 라벨링까지
  되면 "더할 나위 없다".
- **들찍 모드** (사람을 따라가게 줌/프레이밍해주는 자동 편집): "그것만
  해도 쓸 것 같아. 이거 해주면 원탑." 골반/머리 추적, 미디어파이프
  스켈레톤 수준으로 기술적 가능.
- **문제정의 교정 (인터뷰의 결론)**: "아카이빙 할 곳이 없는 게 아니네.
  할 곳은 많아 — 인스타 계정 파면 되니까. **아카이빙을 하고 싶은데 그
  과정과 분류 작업이 너무 오래 걸리는 거야.**" (티온: "정확히, 아주 정확히")
- 촬영 행태: 풀 수 있을지 모를 때 / 까리한 무브일 때만 찍음 → 한계 도전
  = 실패 영상이 대량 축적되는 구조.
- 목표의 분화: 저티어 땐 "낮은 색 전부 클리어", 고티어는 "어려운 문제
  도전" — 실력형/공유형 목표 설정이 다름.
- 피드백 갈증: "스스로 피드백은 한계가 있어. 훈수질이 필요해." (#3 코치
  요청과 일치)
- 경쟁: **올라(Olla)** — 클라이밍 전용, 혼잡도 주력, 소형 암장 제휴,
  리뷰에 상대 난이도 있음, 완성도 높음. **단 영상 파이프라인은 없음** →
  우리 차별화 지점 확인.

## 2차 종합 — 피벗 결정

1. **문제정의 최종 확정**: 아카이빙할 **곳**이 없는 게 아니다(인스타로
   충분). **과정(선별·트리밍)과 분류 작업이 너무 오래 걸리는 것**이 문제다.
   장벽②(과정)가 주 문제, 장벽①(체계)은 보조로 강등.
2. **솔루션 피벗 — "클라이밍 전용 카메라"**: 앱 내 촬영 → 성공/실패 즉시
   분류 → 실패 일괄 삭제 → 성공은 앞뒤 잘려 저장 → 기록(카운트·태깅)은
   이 플로우의 **부산물** → 인스타 업로드까지 원플로우.
3. **영상 서버 저장 포기**: 로컬(갤러리) + 인스타(외부 스토리지). 서버엔
   메타데이터(기록·태그·통계)만. 비용 구조 해결. (세션당 하이라이트 1개만
   서버 후보 — 아티 제안)
4. 체감 투표는 **옵셔널** (강제 노출 금지).
5. 태깅 데이터는 촬영 플로우에서 여전히 쌓임 → **콜드스타트 전략(도구
   사용=소셜 자산)은 유지됨.**
6. 신규 킬러 후보: 들찍 모드(자동 팔로우 프레이밍) — 티온 "그것만 해도 씀".
7. 세그먼트: 카운터형/하이라이트형 둘 다 수용하는 플로우 필요 (카운트는
   세는 사람에게만 의미, 강제하지 않기).
