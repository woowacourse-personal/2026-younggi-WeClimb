# 문제 검증 인터뷰 스크립트 (10분, 3명)

## 검증하려는 가설

1. **[남긴다]** 클라이머는 완등 순간을 기록하고 싶어하지만, 현재 방식(인스타/메모/카메라 앨범)에 불만이 있다.
2. **[자랑한다]** 완등을 자랑하고 싶은 욕구가 있지만, 그 가치를 알아봐줄 사람에게 닿지 않는다.
3. **[동기]** 실력 척도(V등급)와 성취 기록이 없어서 동기가 이어지지 않은 경험이 있다.
4. **[베타]** 막힌 문제의 베타 영상을 찾으려 시도했지만 실패한 경험이 있다.
5. **[내보내기]** 완등 영상을 인스타에 올리는 과정(편집, 루트 정보 설명)에 마찰이 있다.

**전략과의 연결** (콜드스타트: 기록 도구 → 인스타 내보내기 → 암장 단위 소셜 → 피드)

- 가설 1·3 = **1~2단(기록 도구)의 성패**. 이게 죽으면 쐐기 자체를 재검토.
- 가설 2·5 = **2단(인스타 내보내기)의 수요**. 리캡 카드/오버레이가 성장 채널이 될 수 있는지.
- 가설 4 = **3단(암장 단위 소셜)의 예비 검증**. 지금 죽어도 피벗은 아니고, 3단 시점에 재검증.

## 인터뷰 원칙 (Mom Test)

- 앱 아이디어를 **먼저 말하지 않는다.** 말하는 순간 상대는 평가자가 되어 예의상 칭찬한다.
- 미래 가정("~하면 쓸 건가요?")이 아니라 **과거 행동**("마지막으로 ~한 게 언제예요?")을 묻는다.
- "좋네요"는 데이터가 아니다. **구체적 일화, 시간, 돈, 대체 행동**이 데이터다.
- 상대가 말을 흐리면 "그때 어떻게 하셨어요?"로 행동을 다시 묻는다.

## 스크립트

### 0. 인트로 (30초)

> "클라이밍하는 사람들이 평소에 어떻게 기록하고 공유하는지 알아보고 있어요.
> 정답은 없고, 그냥 평소에 하시는 대로 편하게 얘기해주시면 돼요. 10분이면 끝나요."

⚠️ "앱을 만들고 있다"고 하지 말 것. "알아보고 있다"까지만.

### 1. 워밍업 + 스크리닝 (1분)

- 클라이밍 얼마나 자주 가세요? 주로 어디로 가세요?
- 시작한 지는 얼마나 되셨어요?

→ 메모: 주 N회 / 구력 / 주 암장. (월 2회 미만이면 라이트 유저로 분류해 해석 시 참고)

### 2. 완등의 순간 — [남긴다]/[자랑한다] 검증 (3분)

- **"최근에 진짜 기분 좋았던 완등이 있었어요? 그 얘기 좀 해주세요."**
  (구체적 장면을 끌어내는 앵커 질문. 여기서 나온 문제를 이후 질문에서 계속 참조)
- "그 순간에 영상이나 사진 찍으셨어요?"
  - 찍었다면: **"그 영상 그다음에 어떻게 하셨어요?"** ← 핵심 질문
    (올렸다 / 앨범에만 있다 / 지웠다 — 어디에, 왜)
  - 안 찍었다면: "안 찍은 이유가 있어요?"
- (인스타에 올렸다면) "반응 어땠어요? 누가 봐줬어요?"
  - **"올리기 전에 편집 같은 거 했어요? 뭐가 제일 귀찮았어요?"** ← [내보내기] 검증
  - "영상만 보면 어느 암장 무슨 문제인지 모르잖아요 — 캡션에 그런 거 써서 올린 적 있어요?"
- (앨범에만 있다면) "올릴까 고민은 했어요? 뭐가 걸렸어요?"

**듣고 싶은 신호 ✅**: "클라이밍 안 하는 친구들은 몰라줘서", "부계정 만들었어요",
"올리기 귀찮아서", "편집이 귀찮아서", "앞부분 자르는 게 일이에요",
"무슨 문제인지 매번 캡션에 써요/쓰다 말았어요"
**반대 신호 ❌**: "찍을 생각 자체를 안 해요", "혼자 만족하면 끝이에요",
"그냥 원본 그대로 올려요, 아무 불편 없어요"

### 3. 기록과 성장 — [동기] 검증 (2분 30초)

- "본인이 지금 어느 정도 실력인지 어떻게 알아요? 누가 물어보면 뭐라고 답해요?"
- "작년보다 늘었다는 걸 뭘 보고 느껴요?"
- **"오늘 뭐 풀었는지 기록해본 적 있어요?"**
  - 있다면: "어디에, 어떻게요? 지금도 하세요?" (그만뒀다면 왜)
    - "한 번 기록하는 데 얼마나 걸렸어요? 뭐가 제일 번거로웠어요?" ← 태깅 UX(10초) 기준점
  - 없다면: "궁금한 적도 없었어요?"
- "클라이밍 가기 싫어졌던 시기 있었어요? 뭐가 계기였어요?"

**듣고 싶은 신호 ✅**: "V 몇인지 사실 잘 몰라요", 기록 시도했다가 포기한 일화,
"정체기에 재미없어서 쉬었어요"
**반대 신호 ❌**: "그냥 재밌어서 다니는 거라 실력은 관심 없어요"

### 4. 막힌 문제 — [베타] 검증 (2분)

- **"요즘 안 풀리는 문제 있어요? 그거 풀려고 뭐까지 해봤어요?"**
  (다른 사람 구경 / 직접 물어봄 / 인스타 검색 / 유튜브 — 뭐든 실제 행동)
- (인스타 검색이 나오면) "찾아졌어요? 어떻게 검색했어요?"
- "다른 사람이 그 문제 푸는 영상이 있다는 걸 알면, 실제로 찾아본 적 있어요?"

**듣고 싶은 신호 ✅**: 해시태그 검색 실패 경험, "암장에서 잘하는 사람 붙는 거
기다렸다가 구경해요" 같은 우회 행동
**반대 신호 ❌**: "그냥 몸으로 부딪혀요, 남 베타 안 봐요"

### 5. 마무리 (1분)

- "지금 얘기한 것들 중에 제일 아쉬운 거 하나만 꼽으면 뭐예요?"
  (본인 입으로 우선순위를 말하게 함 — 우리가 정한 우선순위와 비교)
- (여기서만, 원하면) "사실 이런 걸 만들어보려고 하는데…" 한 줄 소개 후:
  **"주변에 이거 필요할 것 같은 사람 있어요?"**
  ("쓸 거예요?"보다 정직한 답이 나오는 질문. 소개해준다면 진짜 신호)
- "고마워요. 나중에 프로토타입 나오면 보여드려도 돼요?"

## 3명 끝난 뒤 판정 기준

- 가설별로 **3명 중 2명 이상**이 구체적 일화(✅)를 말하면 유지, 아니면 재검토.
- "예의상 긍정"(일화 없이 "좋네요"만)은 ❌로 센다.

**결과 → 전략 결정 매핑**

| 결과 | 결정 |
|---|---|
| 가설 1·3(남긴다/동기) 강함 | 기록 도구 쐐기 확정 → MVP 그대로 진행 |
| 가설 2·5(자랑/내보내기) 강함 | 리캡 카드·오버레이 내보내기를 MVP에 포함 (성장 채널) |
| 가설 4(베타)만 유독 강함 | 3단(암장 단위 루트 페이지)을 앞당기는 것 검토 — 단 한 암장 집중 조건은 유지 |
| 가설 1·3 죽음 | 쐐기 재검토 (기록 도구가 아닌 다른 진입점 필요) — 피벗 논의 |
