# Gemini Canvas 프로토타입 프롬프트 (Day 1 제출용)

> 반영된 인터뷰 검증 사항:
> - 기록은 세션 중 최소화 + 세션 후 일괄 입력 (#1 "집 갈 때 한 바퀴 회상", #3 "30분 빡빡하고 나감")
> - 필수 입력은 색깔뿐, 벽은 선택 (#3 "어떻게 기록해야 할지 모르겠다" — 체계는 주되 부담은 최소)
> - 뿌듯한 문제만 영상 (#1·#3 선택적 기록)
> - 체감 난이도 투표 (#1 "빨강에 가까운 핑크")
> - "세팅 교체돼도 기록은 남는다" = 핵심 문제정의의 시각화
> - 동네 암장 포함 더미 데이터 (#3 닻 클라이밍)

---

아래를 Gemini Canvas에 그대로 붙여넣기:

```
볼더링(실내 클라이밍) 기록 앱 "클라임로그"의 인터랙티브 프로토타입을
단일 HTML 모바일 웹앱으로 만들어줘. 폭 390px 중앙 정렬, 한국어 UI,
다크 테마(배경 #111), 클라이밍 홀드 색깔(노랑·초록·파랑·빨강·보라)을
포인트 컬러로. 하단 탭바 3개: [기록] [아카이브] [성장].

공통 원칙: 모든 인터랙션(버튼, 탭 전환, 모달, 카운트)이 실제로 동작해야
하고, 데이터는 전부 진짜같은 한국 더미 데이터를 쓸 것.

━━━ 탭 1: 기록 ━━━
상태가 3단계로 전환되는 세션 플로우.

(1) 시작 전: "오늘 어디서 클라이밍해요?" + 암장 검색창.
    누르면 목록 표시: 닻 클라이밍(집 근처), 더클라임 양재, 더클라임 강남,
    손상원클라이밍 판교. 하나 선택하면 [세션 시작] 버튼 활성화.

(2) 세션 중: 운동에 집중하는 최소 UI.
    상단에 암장명 + 큰 타이머(00:47:12부터 자동 증가).
    가운데에 색깔 칩 6개(하양·노랑·초록·파랑·빨강·보라) — 탭하면
    완등 카운트 +1 (햅틱 느낌의 애니메이션). 그게 전부.
    하단에 [세션 종료] 버튼.

(3) 세션 종료 — "한 바퀴 돌아보기" 화면 (이 프로토타입의 하이라이트):
    "수고했어요! 오늘 푼 문제, 한 바퀴 돌아볼까요?"
    - 색깔별 완등 개수 확인/수정 (스테퍼)
    - "뿌듯했던 문제가 있어요?" → [+ 완등 하이라이트 추가] 버튼 →
      모달: 영상 첨부(더미 버튼), 벽 선택(선택사항: A벽/B벽/C벽/모름),
      체감 난이도 원탭 [쉬웠어요 😌 / 딱 맞아요 👍 / 윗 색깔 수준인데? 🔥]
      — 탭하면 바로 닫힘 (10초 안에 끝나는 느낌 강조)
    - 완료하면 오늘 요약 카드: "닻 클라이밍 · 1시간 12분 · 12문제 ·
      최고 파랑" + [기록 저장] 버튼

━━━ 탭 2: 아카이브 ━━━
"세팅은 바뀌어도, 내 기록은 남아요" 라는 카피가 상단에.
완등 하이라이트 카드 2열 그리드 8개. 각 카드: 영상 썸네일 느낌의
그라데이션 더미(재생 아이콘), 라벨 "파랑 · 닻 클라이밍 B벽 · 7월 1주",
체감 난이도 이모지.
지난 세팅 카드 4개에는 회색 뱃지 "🔄 세팅 교체됨 — 기록은 남아있어요".
상단 필터 칩: [전체] [현재 세팅] [지난 세팅] — 실제로 필터링 동작.

━━━ 탭 3: 성장 ━━━
- 상단: 추정 실력 게이지 "V3" + "V4까지 68%" 프로그레스 바.
  아래 작은 설명: "완등 기록과 체감 난이도 투표로 계산돼요 —
  암장이 달라도 비교 가능한 나의 척도"
- 최근 6개월 월별 완등 수 막대그래프 (2~5월 완만, 6~7월 상승).
- 색깔별 완등 분포 도넛 또는 가로 막대.
- "7월 리캡" 카드: 인스타 스토리(9:16) 비율 미리보기 —
  "7월의 클라이밍: 방문 9회 · 완등 41문제 · 최고 파랑 · 새 암장 2곳"
  + [인스타 스토리로 공유] 버튼(누르면 "공유 준비 완료!" 토스트).

마지막으로 첫 로드 시 탭1의 (1)시작 전 화면이 보이게 하고,
데모 편의를 위해 우상단에 작은 "데모: 종료 화면 바로가기" 링크를 넣어줘.
```

## 심사/공유 때 말할 스토리 (30초)

1. **[기록]** 세션 중엔 탭 한 번(운동 흐름 안 끊김), 끝나면 "한 바퀴
   돌아보기"로 10초 정리 — 인터뷰에서 나온 실제 행동을 그대로 화면화.
2. **[아카이브]** 세팅이 교체돼도 내 완등은 남는다 — 문제정의의 시각화.
3. **[성장]** 암장이 달라도 비교되는 나만의 척도 + 인스타로 자랑 —
   동기 루프의 완성.
