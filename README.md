# WeClimb 🧗

> 클라이밍 영상을 촬영부터 성공/실패 분류, 트리밍, 기록, 공유까지
> 한 플로우로 처리해주는 클라이머용 영상 아카이빙 앱

## 문제

클라이머는 완등의 순간을 아카이빙하고 싶어한다. 아카이빙할 곳은 이미 있다
(인스타 부계면 충분하다). 문제는 **과정**이다 — 한 세션에 50~100개씩 쌓이는
시도 영상에서 성공 컷을 골라내고, 앞뒤 죽은 시간을 잘라내고, 무슨 문제였는지
표기하는 정리 노동이 등반 시간보다 길다. 그래서 성취의 영상은 정리되지 못한
채 앨범에서 죽는다.

*(유저 인터뷰 6회로 검증 — [interview-results.md](docs/interview-results.md))*

## 솔루션

**"클라이밍 전용 카메라"** — 등반 내내 이 앱으로만 찍으면, 분류·트리밍·기록·
인스타 업로드가 저절로 끝난다.

```
앱 내 촬영 → 성공/실패 원탭 분류 → 실패 컷 일괄 삭제 → 성공 컷 앞뒤 트리밍
→ 갤러리 저장 + 자동 카운트·태깅 → (세션 종료) 인스타 업로드
```

영상은 로컬 + 인스타에, 서버에는 기록(메타데이터)만 저장한다.

## MVP (v0.1)

앱 내 촬영 + 성공/실패 버튼 + 실패 일괄 삭제 + 앞뒤 수동 자르기 +
자동 카운트/아카이브.

검증 질문: **"클라이머가 등반 내내 이 앱으로만 찍는가?"**

## 로드맵

| 단계 | 내용 |
|---|---|
| 1단 (MVP) | 클라이밍 전용 카메라 — 혼자 써도 가치 있는 도구 |
| 2단 | 인스타 업로드 원플로우·리캡 카드 — 유입 채널 |
| 3단 | 암장 단위 소셜 — 루트별 베타 영상, 체감 난이도 집계 (암장당 활성 20~30명 도달 시) |
| 4단 | 피드, B2B 세터 대시보드 |
