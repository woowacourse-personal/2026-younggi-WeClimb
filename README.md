# ✦ We-Climb

**클라이밍 영상을 촬영부터 분류·트리밍·기록·공유까지 한 플로우로 처리해주는
클라이머용 영상 아카이빙 앱**

> **불편**

클라이밍을 하면서 깔끔하게 아카이빙하고 싶다.
하지만 어떻게 분류해야 할지도 모르겠고, 그 창구도 애매하다.
뿐만 아니라 영상 분류 작업과 편집 과정 또한 너무 불편하다.

> **문제정의**

클라이머는 완등의 기록을 깔끔하게 아카이빙하고 싶어한다.
그러나 문제에는 이름이 없고 벽은 매주 교체되어 무엇을 기준으로 분류해야
할지 알 수 없고, 한 세션에 수십 개씩 쌓인 시도 영상에서 성공 컷을 골라내고
죽은 시간을 잘라내고 라벨을 붙이는 정리 과정은 전부 수동 노동이다 —
등반 시간보다 편집 시간이 길다.
기준도 없고 과정도 고통스러우니, 성취의 영상은 어디에도 정리되지 못한 채
카메라 앨범에서 실패 컷들과 뒤섞여 죽는다.

> **솔루션**

**"찍기만 하면, 정리는 앱이 한다"** — 클라이밍 전용 카메라이자 성취 아카이브.
앱 안에서 촬영하고, 시도가 끝날 때마다 성공/실패 버튼 하나로 분류한다.
실패 컷은 한 번에 비우고, 성공 컷은 앞뒤가 잘린 채 저장되며, 그 순간
기록(암장 × 벽 × 색깔 × 문제)이 함께 쌓인다. 세션이 끝나면 그대로 인스타에
올리는 것까지가 한 플로우.
쌓인 기록은 실력 척도(V등급 추정)와 자랑거리(인스타 리캡·오버레이)로
되돌아와 다음 도전의 동기가 된다.

---

> **한 세션의 흐름**

```
암장 선택 → 색깔 선택 → 촬영 → [성공 / 실패]
                              ├─ 실패 → 한 번에 비우기
                              └─ 성공 → 앞뒤 트리밍 → 저장 + 카운트 자동 기록
세션 종료 → 오늘의 기록 요약 → 인스타 업로드
```

> **지금 만드는 것 (MVP)**

앱 내 촬영 · 성공/실패 원탭 분류 · 실패 일괄 삭제 · 앞뒤 트리밍 ·
자동 카운트/아카이브 — 여기까지.
검증하려는 단 하나의 질문: **"클라이머가 등반 내내 이 앱으로만 찍는가?"**

> **그 다음**

기록이 쌓이면 앱은 도구에서 커뮤니티로 자란다.
암장별로 유저가 모이는 순간, 내 기록은 다른 사람의 **베타(정답지)** 가 되고 —
루트별 영상 모아보기, 체감 난이도 집계, 세터/암장용 데이터까지 이어진다.
