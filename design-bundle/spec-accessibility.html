3 · 터치 타깃

요소시각 크기터치 영역비고
결과 버튼 (성공/실패)100dp 높이충분간격 12dp (≥8dp 오탭 방지)
녹화 · 정지 버튼78dp 원형충분화면 하단 중앙, 엄지 도달권
시트 옵션 행64dp 높이충분행 전체가 탭 영역
다이얼로그 버튼50dp 높이충분세로 스택, 간격 10dp
색 카운트 행56dp 높이충분행 전체 탭 = 카운트 +1
아카이브 카드 액션36dp 높이확장 필요수직 패딩으로 ≥48dp 확장 (minimumInteractiveComponentSize)
타임라인 핸들16×40dp확장 필요좌우 ≥48dp 히트박스 별도 지정. 시각 폭은 정밀도를 위해 유지
플레이어 아이콘 버튼44dp 원형확장 필요48dp로 패딩 확장
필터 칩36dp 높이확장 필요미리보기 상태이지만 활성화 시 확장 필요
시각 크기 ≠ 터치 크기. 타임라인 핸들처럼 정밀 조작을 위해 얇아야 하는 요소는 시각 폭을 유지하되 히트박스만 넓힌다. Compose에서는 Modifier.minimumInteractiveComponentSize() 또는 Modifier.padding() + clickable 순서로 확보한다.

4 · TalkBack

요소contentDescription / 읽히는 내용비고
색 카운트 행"파랑 완등 7개, 두 번 탭하면 하나 추가, 길게 누르면 수정"탭 후 liveRegion으로 "파랑 완등 8개, 되돌리기 가능" 재공지
녹화 버튼"녹화 시작" / "녹화 정지, 8초 경과"타이머 값을 라벨에 포함
녹화 인디케이터"녹화 중"펄스 애니메이션과 무관하게 항상 읽힌다
결과 버튼 3개"실패, 영상도 지웁니다" / "완등, 완등 1개 추가하고 영상 보관" / "실패지만 영상은 남기기"영상 결과를 반드시 읽는다. 처리 중에는 "저장 중, 사용할 수 없음"
아카이브 카드"완등, 닻 클라이밍, 파랑, 7월 22일 오후 8시 14분, 트리밍 완료"카드 전체를 mergeDescendants로 한 노드
읽기 불가 카드"…, 기기에서 삭제됨, 재생할 수 없음"액션 노드 없음
타임라인 핸들"시작 지점 5초" / "끝 지점 20초"ProgressBarRangeInfo + 좌우 스와이프 조정 액션
진행 링"영상 자르는 중 45퍼센트"liveRegion = Polite, 10% 단위로만 공지
되돌리기 칩 · 배너"되돌리기 가능, 5초" → 조작 후 "되돌렸어요"TalkBack 활성 시 창 연장. 5초는 읽고 조작하기에 짧다
조정 시트 잠금"영상이 있는 시도 3개는 잠겨 있어요, 빼기 사용할 수 없음"비활성 이유를 반드시 읽는다
오류 배너"오류: 저장에 실패했어요. 원본은 그대로 있어요"liveRegion = Assertive — 즉시 공지
성공 배너"영상을 저장했어요"liveRegion = Polite
파괴적 확인제목 → 남는 것 → 사라지는 것 → 버튼 순다이얼로그 진입 시 제목에 포커스
미리보기 블록"미리보기, Phase 3 비활성. 사용할 수 없음"내부 요소는 clearAndSetSemantics로 숨김 — 가짜 값을 읽히지 않는다
플레이어 진행 바"재생 위치 5초, 전체 15초"탐색 액션 제공
플레이스홀더 썸네일읽지 않음 (장식)contentDescription = null
미리보기 블록의 가짜 값을 TalkBack이 읽으면 안 된다. "Lv.5 파랑", "78%", "14 완등" 같은 정적 예시가 음성으로 읽히면 시각 신호(점선·워터마크·감쇠)가 전혀 전달되지 않아 실제 데이터로 오인된다. 블록 전체를 하나의 비활성 노드로 병합하고 내부를 clearAndSetSemantics {}로 비운다.

5 · 포커스 순서

화면포커스 순서초기 포커스
05 분류 대기뒤로 → 녹화 정보 → 실패 → 완등 → 실패지만 영상은 남기기질문 텍스트
05 되돌리기 배너문구 → 되돌리기 버튼문구 (liveRegion = Assertive)
04 조정 시트색 헤더 → 값 → − → + → 잠금 안내 → 완료값 (조정 대상)
05b 폐기 확인제목 → 남는 것 → 사라지는 것 → 파괴 → 취소제목. 파괴 버튼에 자동 포커스 금지
06 트리밍닫기 → 정보 → 프리뷰 → 재생 → 시작 핸들 → 끝 핸들 → 범위 라벨 → 원본 유지 → 저장 → 나중에제목
06 처리 중진행 상태 → 취소진행 상태 (liveRegion). 다른 노드는 포커스 불가
07 아카이브제목 → 개수 → (필터) → 카드 1..n → 탭 바제목
08 재생닫기 → 영상 정보 → 공유 → 재생/일시정지 → 진행 바 → 공유 바영상 정보
04 종료 보류제목 → 경고 → 요약 → 재저장 → 폐기 → 계속제목. 폐기가 첫 포커스가 되지 않게
모달 포커스 트랩 — 시트·다이얼로그·처리 오버레이가 떠 있는 동안 뒤 화면 노드는 접근성 트리에서 제외한다. Compose: 뒤 컨테이너에 Modifier.semantics { invisibleToUser() }.

6 · 축소 모션 · 큰 글자

설정대응
축소 모션모든 --dur-* → 0ms. 무한 반복(펄스 · 스피너 · shimmer)은 정적 표시 + 텍스트 라벨로 대체. 드래그·스크럽 추종은 유지
큰 글자 (200%)결과 버튼 라벨 2줄 허용, 소제목 말줄임. 카드 높이는 wrapContent. 고정 높이 금지 — 시안의 dp 값은 100% 기준
굵은 텍스트시스템 설정 존중. 시안의 weight 600/700 유지
375dp 소형 폰결과 버튼 간격 12dp → 8dp까지 축소 허용. 시트 옵션은 아이콘 유지, 부제 2줄 허용
고대비Outline rgba(255,255,255,.10) → .24로 강화. pill 테두리 추가
축소 모션에서도 정보 손실이 없어야 한다. 녹화 중 · 처리 중 · 버퍼링 · 로딩 네 상태는 모션이 유일한 신호가 되기 쉽다. 모두 텍스트 라벨을 상시 병기하도록 시안에 고정했다.

7 · 세이프 에어리어 · 레이아웃

항목규칙
상단 상태바44dp 확보. 촬영·재생의 전체 화면 오버레이도 컨트롤을 그 아래 배치
하단 제스처 인디케이터바텀 탭 padding-bottom: 8dp, 시트 padding-bottom: 30dp
스크롤 콘텐츠고정 바텀 탭에 가리지 않도록 contentPadding 적용
시트 최대 높이화면의 80%. 초과 시 시트 내부 스크롤, grab 핸들은 고정
배너콘텐츠를 밀지 않는 오버레이 배치 — 레이아웃 점프 방지
스켈레톤실제 카드와 동일 높이. 도착 시 점프 없음
오류 문구 자리범위 무효 문구는 자리를 미리 예약해 나타날 때 밀리지 않게

8 · 인지 부하 · 문구

규칙적용
파괴적 결과를 사전 고지확인 다이얼로그에 남는 것 / 사라지는 것을 분리 나열. "정말?" 금지
닫기 결과를 사전 고지시트 하단에 "닫으면 나중에와 같아요" 문장 상시 표시
오류에 보존 사실 병기모든 오류 문구는 원인 + 무엇이 남았는지 2줄 구조
사용자 탓 표현 금지"잘못된 입력" → "끝 지점이 시작보다 뒤여야 해요"
기술 용어 노출 금지예외 원문 · 코덱명 · 실패 횟수를 화면에 쓰지 않는다
막다른 길 금지모든 오류 상태에 최소 2개의 출구(재시도 + 대안)
세션 중 결정 최소화결과와 영상 보관을 한 번의 탭으로 묶고, 자르기는 아카이브로 미룬 v2의 근거. 벽 앞에서 고민하게 만들지 않는다

9 · 인수 전 체크리스트

  • 본문 대비 ≥4.5:1, 보조 ≥3:1, 구분선 다크에서 가시
  • 브랜드·성공 색 위 흰 텍스트는 18sp 이상 굵게만
  • 홀드 색 스와치에 한글 색 이름 병기
  • 결과 배지와 미디어 pill에 아이콘 + 라벨 병기
  • 터치 타깃 ≥48×48dp, 성공/실패 간격 ≥8dp
  • 타임라인 핸들 히트박스 ≥48dp로 확장
  • 모든 색 칩·버튼에 contentDescription
  • 미리보기 블록은 clearAndSetSemantics로 내부 값 숨김
  • 오류 배너 liveRegion = Assertive, 진행 Polite
  • 파괴적 다이얼로그 초기 포커스는 제목 (파괴 버튼 아님)
  • 모달 뒤 화면 invisibleToUser 포커스 트랩
  • 축소 모션에서 정보 손실 없음 (텍스트 라벨 상시)
  • 큰 글자 200%에서 레이아웃 미파손, 고정 높이 없음
  • 375dp 소형 폰 세로에서 확인
  • 세이프 에어리어 침범 없음, 탭 바 뒤 콘텐츠 가림 없음
  • 스켈레톤 = 실제 카드 높이, 레이아웃 점프 없음
  • 눌림이 레이아웃을 밀지 않음 (ripple만)
  • 모든 오류 상태에 출구 2개 이상
  • 아이콘은 벡터, 이모지 금지
  • 기능 표면에 가짜 값 없음 (레벨·길이·개수·타임스탬프)
  • 되돌리기 창이 TalkBack에서 연장됨
  • 결과 버튼 3개가 영상 결과를 음성으로 전달함
  • 조정 시트의 − 비활성 이유가 읽힘
